# Desafio dos R$ 10.000 — site

Esta é a versão 2 do projeto.

## O que já funciona
- Tabela com 210 valores totalizando R$ 10.000.
- Marcar/desmarcar valores.
- Cálculo de total, restante e percentual.
- Layout responsivo para celular e PC.
- Salvamento local no navegador.
- Tela de login preparada visualmente.

## Importante sobre acesso de qualquer lugar
Para sincronizar o progresso entre celular e PC de verdade, o projeto precisa de um serviço de autenticação + banco de dados (por exemplo, Supabase ou Firebase) e de hospedagem. O HTML desta pasta ainda não envia senha ou progresso para a internet.

## Como testar
Abra `index.html` no navegador.

## Próxima etapa
Conectar o login e o progresso a um banco online e publicar o site em uma hospedagem. Depois disso você terá um endereço público e poderá acessar o mesmo progresso de qualquer lugar.
